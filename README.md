# VS Code Theme Portfolio

A modern, VS Code-inspired portfolio website that showcases your professional information in a code editor aesthetic.

## Features

✨ **Clean VS Code Design** - Modern dark theme with familiar code editor interface

📱 **Responsive Layout** - Works seamlessly on desktop and mobile devices

⚡ **Easy Navigation** - Smooth transitions between sections

🎨 **Syntax Highlighting** - Professional code-style formatting

## Sections

### 1. Introduction
- Personal information display
- Name, title, and contact details
- Social media links

### 2. Background
- Educational background
- Personal bio and about information

### 3. Skills
- Frontend technologies
- Backend technologies
- Development tools
- Programming languages

### 4. Experience
- Job positions and companies
- Duration and dates
- Job descriptions

### 5. Awards
- Awards and recognitions
- Organizations and years
- Achievement highlights

## How to Use

1. Clone or download this repository
2. Edit the content in `index.html` to replace placeholder text with your information
3. Customize colors in `styles.css` if desired
4. Open `index.html` in your browser

## Customization

### Change Color Scheme
Edit the CSS variables in `styles.css`:

```css
:root {
    --bg-primary: #1e1e1e;      /* Main background */
    --text-primary: #d4d4d4;    /* Main text */
    --accent-blue: #007acc;     /* Accent color */
}
```

### Update Your Information
Replace the placeholder text in each section:
- Your Name
- Your Title
- Email and Location
- Education details
- Skills list
- Work experience
- Awards and achievements
